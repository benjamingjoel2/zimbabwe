# Facts to verify

The site's content was written from general knowledge, not checked against current official sources. **Every item below must be confirmed before launch** and rechecked at least once a year. Visa rules, park fees and access change often.

How the markers work: a claim in the source (`src/`) is followed by a marker like `[F12]`. The build turns markers into HTML comments (`<!-- F12 -->`), so they are invisible on the page but you can still find them in the page source. `npm run check` fails if a marker in `src/` has no entry here. When a fact is confirmed, you can delete its marker from the source and tick it here. Don't renumber the others.

Status key: ☐ not yet checked · ☑ checked (add date and source)
